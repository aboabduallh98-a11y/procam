# ProCam — تطبيق كاميرا احترافي (Note 10+ / أندرويد 12)

## كيف تحصل على ملف APK (بدون أي برمجة)

### 1) فك الضغط
فك ضغط الملف `ProCam.zip` على جهازك. ستجد مجلداً اسمه `ProCam`.

### 2) أنشئ مستودعاً على GitHub
1. ادخل github.com وسجّل الدخول.
2. اضغط علامة **+** أعلى الصفحة ثم **New repository**.
3. اكتب اسماً (مثلاً `procam`)، واختر **Private** إن أردت، ثم **Create repository**.

### 3) ارفع الملفات
1. في صفحة المستودع اضغط **uploading an existing file** (أو Add file ← Upload files).
2. افتح مجلد `ProCam` على جهازك، حدّد **كل** ما بداخله (بما فيه المجلد `.github` والمجلد `app`) واسحبه إلى الصفحة.
3. انتظر انتهاء الرفع ثم اضغط **Commit changes**.

> **مهم:** تأكد أن الملف `.github/workflows/build.yml` ظهر في المستودع.
> إن لم يظهر (بعض الأجهزة تخفي المجلدات التي تبدأ بنقطة):
> اضغط Add file ← **Create new file**، اكتب في خانة الاسم بالضبط: `.github/workflows/build.yml`
> ثم الصق بداخله محتوى الملف `build.yml` الموجود في هذا المجلد، واضغط Commit.

### 4) انتظر البناء
1. افتح تبويب **Actions** في المستودع.
2. سترى عملية اسمها **Build APK** تعمل (دائرة صفراء). تستغرق 5–10 دقائق.
3. عند ظهور علامة ✅ الخضراء، اضغط على العملية.

### 5) نزّل التطبيق
1. انزل إلى قسم **Artifacts** في أسفل الصفحة.
2. اضغط **ProCam-APK** فيُنزَّل ملف zip، فك ضغطه تجد `app-debug.apk`.
3. انقله إلى هاتفك (أو نزّله مباشرة منه) واضغط عليه للتثبيت، وافسح "التثبيت من مصدر غير معروف" إن طلب.

### إن ظهرت علامة ❌ حمراء
افتح العملية الفاشلة، وانسخ نص الخطأ (أو صوّره) وأرسله لي لأصلحه فوراً.

## دليل الاستخدام

| الزر | وظيفته |
|---|---|
| PHOTO / VIDEO | التبديل بين التصوير والفيديو |
| الدائرة الكبيرة | التقاط صورة / بدء وإيقاف التسجيل (يعمل بأزرار الصوت أيضاً) |
| الزر السفلي الأيمن (Back 26mm ...) | اختيار العدسة |
| EV | تعويض التعريض (في الوضع التلقائي) |
| ISO / SS | تحكم يدوي بحساسية الضوء وسرعة الغالق. زر AUTO يرجعهما تلقائياً |
| FOCUS | تحكم يدوي بالفوكس (AF = تلقائي) |
| WB | توازن الأبيض |
| RES / FPS / CODEC / Mbps | دقة الفيديو، الإطارات، الكودك (H.264 / HEVC)، جودة التسجيل |
| RAW | حفظ صورة DNG مع JPEG (إن دعمتها العدسة) |
| HIST | رسم Histogram |
| ZEBRA | خطوط حمراء على المناطق المحروقة (فرط التعريض) |
| PEAK | خطوط خضراء على الحواف الواضحة (Focus Peaking) |
| GRID | شبكة الأثلاث |

الملفات تُحفظ في معرض الصور داخل المجلد **DCIM/ProCam**.

## ملاحظات
- التطبيق يعمل بوضع أفقي فقط.
- سامسونج قد تمنع التطبيقات الخارجية من بعض العدسات. إن لم تعمل عدسة، سيرجع التطبيق للعدسة الرئيسية تلقائياً.
- ما يظهر في قائمة العدسات هو ما تسمح به سامسونج فقط.
